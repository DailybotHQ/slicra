# Testing guide

Framework: **pytest 9.1.1** (tests in `tests/`, files `test_<area>.py`), with ruff 0.17.0 and
mypy 2.4.0 as static gates. All commands run from the repository root with the project venv
active (or prefixed with `.venv/bin/`). Versions are the ones verified on 2026-10-14.

## 1. Full commands (current, verified)

| Gate | Command | Notes |
| --- | --- | --- |
| Tests (all) | `python -m pytest` | ~30-45 s; includes the slow packaging test |
| Tests (fast) | `python -m pytest -m "not slow"` | ~9 s; 129 tests on a dev machine |
| Lint | `ruff check src tests examples` | |
| Format | `ruff format --check src tests examples` | |
| Types | `mypy` | strict, package `slicra` (config in `pyproject.toml`) |
| Packaging | `python -m pytest -m slow` | builds wheel + sdist, installs in a clean venv, runs `slicra` |

The fast suite finishes in seconds, so **prefer running it whole** over elaborate selection.

## 2. Scoped invocation (verified on this repository)

| Scope | Example | Verified evidence |
| --- | --- | --- |
| File | `python -m pytest tests/test_grid.py` | 29 collected, 29 passed |
| Name expression | `python -m pytest -k manual` | 11 of 130 selected |
| Marker | `python -m pytest -m slow` | 1 of 130 selected |
| Node id | `python -m pytest tests/test_cli.py::test_batch_directory` | single test |
| Dry run of a selection | `python -m pytest --co -q <selection>` | prints the count; check it is non-zero |

Zero selection is not a pass: pytest exits **5** when nothing is collected and **4** for a bad
path. Markers are declared in `pyproject.toml`: `slow` (build/install) and `real` (local sample
sheets).

Static checks: `ruff check <path>` and `ruff format --check <path>` scope natively. `mypy` should
run project-wide (`mypy`), because a partial run can miss cross-module errors; it takes a few
seconds.

## 3. Source-to-test mapping

| Source | Tests |
| --- | --- |
| `src/slicra/detectors/grid.py` | `tests/test_grid.py` |
| `src/slicra/detectors/grid_auto.py`, `background.py` | `tests/test_grid_auto.py` (+ `test_api.py` auto mode, `test_real_samples.py`) |
| `src/slicra/detectors/contours.py`, `ordering.py` | `tests/test_contours.py` |
| `src/slicra/detectors/manual.py` | `tests/test_manual.py` |
| `src/slicra/detectors/__init__.py` (registry, auto) | `tests/test_api.py` |
| `src/slicra/masks/shapes.py`, `extraction.py` | `tests/test_masks.py`, `tests/test_export.py` (resize) |
| `src/slicra/export.py`, `preview.py` | `tests/test_export.py`, `tests/test_end_to_end.py` |
| `src/slicra/imageio.py` | `tests/test_end_to_end.py` (EXIF, corrupt, limits, batch) |
| `src/slicra/config.py`, `init_templates.py`, `presets/` | `tests/test_api.py`, `tests/test_cli.py`, every detector test |
| `src/slicra/cli.py` | `tests/test_cli.py` |
| `src/slicra/pipeline.py` | `tests/test_api.py`, `tests/test_end_to_end.py` |
| `skills/slicra/` | `tests/test_skill.py` (+ `agentskills validate skills/slicra` when installed) |
| `examples/configs/`, `examples/generate_fixtures.py` | `tests/test_end_to_end.py`, `tests/conftest.py` |
| `pyproject.toml`, package data | `tests/test_packaging.py` |

**Consumer policy.** There is no affected-tests tool; the import graph is small. `config.py`,
`models.py`, `pipeline.py`, `errors.py` and `tests/conftest.py` are shared by everything, so a
change there runs the full fast suite.

**Blind spots.** Package data (`presets/*.yaml`, `py.typed`) and the console-script entry point
are only exercised by the slow packaging test. Optional-dependency behavior without OpenCV is
only exercised by the CI job `core-without-opencv` (or a local venv without the extra).
Cross-platform path behavior is only covered by the CI matrix.

## 4. Escalation and fallback

- Always run the **full** suite (`python -m pytest`) for changes to `pyproject.toml`, presets,
  `config.py`, `models.py`, `pipeline.py`, `errors.py`, `cli.py`, `conftest.py` or the CI file.
- Run `python -m pytest -m slow` whenever packaging, entry points or package data change.
- **Fallback:** when unsure what a change affects, run
  `ruff check src tests examples && ruff format --check src tests examples && mypy && python -m pytest`.

## 5. Layers and posture

- **Unit / behavioral (base):** detector and mask tests on synthetic images with known geometry,
  asserting pixels, boxes, alpha and warnings (`test_grid.py`, `test_masks.py`, ...).
- **Integration seams:** the CLI via `typer.testing.CliRunner` (`test_cli.py`: arguments → files
  → exit codes); the API end to end (`test_end_to_end.py`: example configs, manifest vs files,
  EXIF, batch); packaging (`test_packaging.py`).
- **Real-data regression (optional, local):** `test_real_samples.py` runs only when
  `SLICRA_SAMPLES` (or `../avatars-grids`) contains sheets; CI never needs it.
- Fixtures are generated by code (`examples/generate_fixtures.py`, `tests/conftest.py`):
  deterministic, no photographs. Prefer real behavior over mocks; do not assert internal call
  sequences.
- Every bug fix adds a regression test that fails before the fix.

No proposed setup is pending: the toolchain above is in place and verified.
