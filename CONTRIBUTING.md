# Contributing to Slicra

Thanks for helping. Slicra values a small, solid core over many half-working features.

## Setup

```bash
git clone https://github.com/DailybotHQ/slicra.git && cd slicra
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"
python examples/generate_fixtures.py
```

## Before opening a pull request

```bash
ruff check src tests examples
ruff format --check src tests examples
mypy
python -m pytest                 # add -m "not slow" to skip the wheel build test
```

- Tests check **pixels**, not just that files exist. Fixtures are synthetic and generated by code;
  never add photographs of real people or private data.
- Keep the CLI, the README, the Agent Skill and `examples/configs/` in sync with the code: do not
  document a command or option that does not exist.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`,
  `docs:`, `test:`, `refactor:`, `chore:`).
- Update [CHANGELOG.md](CHANGELOG.md) under *Unreleased*.

## Adding a detector

1. Add a configuration model to `src/slicra/config.py` with a unique `mode: Literal["..."]` and add
   it to the `Detection` union. Use `StrictModel` so unknown keys fail.
2. Implement `detect_<name>(image, cfg) -> DetectionResult` in `src/slicra/detectors/<name>.py`.
   Return regions with `bbox` in source pixels (exclusive right/bottom), stable ids and order
   (`slicra.ordering.reading_order` for free-form regions), and `DetectionWarning`s for anything
   doubtful. Raise `DetectionError` instead of guessing.
3. Register it in `src/slicra/detectors/__init__.py` (or call `slicra.register_detector` from a
   plugin). Optional heavy dependencies must be imported lazily and raise `MissingDependencyError`
   with an install hint.
4. Add tests with synthetic fixtures, a `slicra init` starter if useful, and docs.

## Adding a mask shape

1. Add the name to `ShapeName`/`SHAPES` and any options to `Extraction` in `config.py`.
2. Draw it in `src/slicra/masks/shapes.py::build_mask`, respecting `shape_inset`, anti-aliasing via
   supersampling, and the rule that parametric shapes fit the region box while geometric shapes use
   source coordinates.
3. Test the alpha channel at known pixels.

## Reporting bugs and security issues

Open an issue with the command, the config and, if possible, a synthetic image that reproduces the
problem. Report security issues privately; see [docs/SECURITY.md](docs/SECURITY.md).

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
